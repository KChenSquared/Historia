# Historia v0.11.0

Only the Windows packages are supported. The MacOSX and Linux packages are experimental.

## Changes

- Push a branch and open a GitHub pull request for it from the branch and graph menus
- Fast-forward a branch without checking it out, and merge-and-push a diverged branch, from branch menus
- One context menu for a commit and its refs in the graph, with remotes nested under each branch and Copy tag name
- Stage, unstage and add to .gitignore from a file's right-click menu in the staging list
- A new CMDR list in the sidebar queues the changes coding agents ask you to review
- AI commit messages no longer block staging or committing; the diff limit is set in tokens (default 25,000) and rate-limit errors name the quota and retry time
- Windows packages bundle MinGit and git-lfs, used when no suitable git is installed (can be turned off in Settings)
- Experimental MacOSX (Apple Silicon and Intel) and Linux packages
- Faster commit graph, status refresh and background fetches, with fewer UI stalls on large repositories
- The main window reopens on a connected screen when a monitor is removed
- Various bug fixes
